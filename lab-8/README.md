# Lab 8 - User Information Form

**Aim:** Design a web page to capture user information such as name, gender, mobile number, mail id, city, state and country using form elements, and display them on another page using JavaScript.

## Files
- `index.html` - form page (text, radio, tel, email inputs and a dropdown)
- `display.html` - page that shows the submitted details
- `style.css` - styling for both pages
- `script.js` - validation, saving data with `localStorage`, and displaying it

## How it works
1. The user fills the form on `index.html`.
2. JavaScript validates every field and shows error messages.
3. On a valid submit, the data is saved in the browser with `localStorage`.
4. The browser opens `display.html`, which reads the saved data and shows it in a table.

## How to run
Open `index.html` in any web browser.

## Technologies
HTML, CSS, JavaScript
