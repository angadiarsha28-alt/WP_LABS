# Lab 7 - Arithmetic Calculator

**Aim:** Design a web page to perform mathematical calculations such as addition, subtraction, multiplication and division using form elements and JavaScript.

## Files
- `index.html` - page structure and form elements
- `style.css` - styling
- `script.js` - calculation logic

## Features
- Two number inputs, operation dropdown, Calculate and Reset buttons
- Validation for empty fields
- Division by zero handling
- Result displayed on the page without reloading

## How to run
Open `index.html` in any web browser.

## Technologies
HTML, CSS, JavaScript
